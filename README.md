## Featured Project

### 🤖 [boss-agent-cli](https://github.com/can4hou6joeng4/boss-agent-cli)

A local-assist BOSS Zhipin CLI built for AI-agent workflows. It searches roles, filters by welfare signals, creates reviewable shortlists, and returns structured JSON-envelope output with low-risk, compliant defaults.

- Search and refine job opportunities from the command line.
- Apply welfare filters and keep candidate lists reviewable.
- Exchange structured results with agents without hiding the underlying evidence.

[Repository](https://github.com/can4hou6joeng4/boss-agent-cli) · [Documentation](https://can4hou6joeng4.github.io/boss-agent-cli/) · [Latest release](https://github.com/can4hou6joeng4/boss-agent-cli/releases/latest)

## Writing

### [Unicode braille is an 8-pixel bitmap font](https://bobochang.cn/writing/unicode-braille-8-pixel-bitmap-font/)

An implementation-focused look at treating each braille character as a 2×4 bitmap, then using Floyd–Steinberg error diffusion to preserve image detail as plain text. The working browser implementation is available in [Semaphore](https://semaphore.bobochang.cn).

## Engineering Principles

- Define system and responsibility boundaries explicitly.
- Keep sensitive data local wherever practical.
- Make automation observable, inspectable, and verifiable.
- Prefer reversible actions and low-risk defaults.

Repository names follow **one word, one image, one emoji**. Names carry identity; descriptions explain function.
