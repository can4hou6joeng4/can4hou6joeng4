## Writing

### [Unicode braille is an 8-pixel bitmap font](https://bobochang.cn/writing/unicode-braille-8-pixel-bitmap-font/)

An implementation-focused look at treating each braille character as a 2×4 bitmap, then using Floyd–Steinberg error diffusion to preserve image detail as plain text. The working browser implementation is available in [Semaphore](https://semaphore.bobochang.cn).

## Engineering Principles

- Define system and responsibility boundaries explicitly.
- Keep sensitive data local wherever practical.
- Make automation observable, inspectable, and verifiable.
- Prefer reversible actions and low-risk defaults.

Repository names follow **one word, one image, one emoji**. Names carry identity; descriptions explain function.
